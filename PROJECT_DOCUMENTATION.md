# Project Documentation

## 1. General Project Description

This project is a web application built using the Laravel framework and Inertia.js. It appears to be a content management system (CMS) or a blogging platform, providing functionalities for managing users, posts, pages, categories, tags, and settings. It includes both a user-facing interface and an administrative panel.

## 2. User-Facing Features

The user-facing part of the application includes:

*   **Homepage:** A main landing page (route: `/`). The specific content of this page is rendered using the `Home` Inertia component.
*   **Locale Switching:** Users can switch the application's language (e.g., English or Arabic) via the `/locale/{locale}` route. This updates the session locale and redirects the user back.

## 3. Admin Panel Features

The application includes a comprehensive admin panel accessible via the `/admin` prefix. It provides the following functionalities:

*   **Authentication:**
    *   Login page for administrators (`/admin/login`).
    *   Logout functionality.
*   **Dashboard:** A central dashboard for the admin panel (`/admin/dashboard`).
*   **Profile Management:**
    *   View and update personal profile information (`/admin/profile`).
    *   Update profile photo.
    *   Change password.
*   **User Management:**
    *   CRUD (Create, Read, Update, Delete) operations for application users (resource route: `/admin/users`).
*   **Category Management:**
    *   CRUD operations for content categories (resource route: `/admin/categories`).
*   **Tag Management:**
    *   CRUD operations for content tags (resource route: `/admin/tags`).
*   **Post Management:**
    *   CRUD operations for blog posts or articles (resource route: `/admin/posts`).
*   **Page Management:**
    *   CRUD operations for static pages (resource route: `/admin/pages`).
*   **Image Upload:**
    *   Functionality to upload images (`/admin/images/upload`). This is likely used by other features like post or page creation.
*   **File Manager:**
    *   A simple file manager to view and create folders (`/admin/file-manager`).
*   **Settings Management:**
    *   Manage application-wide settings (resource route: `/admin/settings`).

## 4. Project Structure

The project follows a standard Laravel application structure:

*   **`app/`**: Contains the core code of the application, including Models, Controllers, Providers, Http middleware, Console commands, and Exceptions.
*   **`bootstrap/`**: Contains files that bootstrap the framework and configure autoloading.
*   **`config/`**: Includes all of the application's configuration files.
*   **`database/`**: Contains database migrations, model factories, and seeders.
*   **`lang/`**: Contains language files for localization (e.g., English, Arabic).
*   **`public/`**: The web server's document root. Contains the `index.php` entry point and publicly accessible assets (images, stylesheets, JavaScript).
*   **`resources/`**:
    *   **`css/`**: Contains CSS files.
    *   **`js/`**: Contains JavaScript files, including Vue components for Inertia.js (`Components/`, `Layouts/`, `Pages/`).
    *   **`views/`**: Contains Blade templates, primarily the main `app.blade.php` for Inertia.
*   **`routes/`**: Contains all route definitions for the application (web, API, console, channels).
*   **`storage/`**: Contains compiled Blade templates, file-based sessions, file caches, and other files generated by the framework.
*   **`tests/`**: Contains automated tests (feature and unit tests).
*   **`vendor/`**: Contains Composer dependencies.
*   **`composer.json`**: Lists project dependencies and other metadata.
*   **`.env`**: Environment configuration file (not version controlled, `.env.example` provides a template).
*   **`artisan`**: The command-line interface included with Laravel.

## 5. Main Technologies Used

*   **PHP**: The primary server-side scripting language.
*   **Laravel Framework**: The backend framework used to build the application.
*   **Inertia.js**: A library that allows building single-page apps (SPAs) using classic server-side routing and controllers, effectively bridging Laravel with client-side JavaScript frameworks.
*   **Vue.js**: (Implied by the use of Inertia.js and `.vue` files in `resources/js/`) The client-side JavaScript framework for building user interfaces.
*   **MySQL/MariaDB**: (Commonly used with Laravel, though the specific database is defined in the `.env` file) The relational database management system.
*   **Vite**: Frontend build tool used for compiling assets.
*   **Tailwind CSS**: (Often used with Laravel and Inertia, and `app.css` likely imports it) A utility-first CSS framework.

## 6. Setup and Running the Project

To set up and run this project locally, follow these steps:

1.  **Clone the Repository:**
    ```bash
    git clone <repository-url>
    cd <project-directory>
    ```

2.  **Install PHP Dependencies:**
    ```bash
    composer install
    ```

3.  **Install NPM Dependencies:**
    ```bash
    npm install
    ```

4.  **Create Environment File:**
    Copy the example environment file and configure it:
    ```bash
    cp .env.example .env
    ```
    *   Open `.env` and set up your database credentials (`DB_HOST`, `DB_PORT`, `DB_DATABASE`, `DB_USERNAME`, `DB_PASSWORD`).
    *   Ensure other necessary configurations like `APP_URL` are set.

5.  **Generate Application Key:**
    ```bash
    php artisan key:generate
    ```

6.  **Run Database Migrations:**
    This will create the necessary tables in your database.
    ```bash
    php artisan migrate
    ```

7.  **Seed the Database (Optional but Recommended):**
    This will populate the database with initial data, such as an admin user.
    ```bash
    php artisan db:seed
    ```
    *   Check `database/seeders/AdminSeeder.php` or `DatabaseSeeder.php` for default admin credentials if provided.

8.  **Compile Frontend Assets:**
    ```bash
    npm run dev
    ```
    Or for production:
    ```bash
    npm run build
    ```

9.  **Set Up File Storage Link (If not already set up):**
    ```bash
    php artisan storage:link
    ```
    This makes the `storage/app/public` directory accessible from `public/storage`.

10. **Serve the Application:**
    ```bash
    php artisan serve
    ```
    The application will typically be available at `http://127.0.0.1:8000` or the `APP_URL` specified in your `.env` file.

**Note:** Ensure you have PHP, Composer, Node.js, NPM, and a compatible database server (e.g., MySQL, MariaDB) installed on your system.
